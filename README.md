## 🚀 Features

| **Feature** | **Description** |
|:---|:---|

| **Plugin Manager** | Organize installed Audacity plugins with type and usage notes |
| **Export Presets** | Save named export settings for podcast, music and audio formats |
| **Episode Tracker** | Track podcast episode production status from recording to publish |
